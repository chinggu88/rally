앱의 핵심 콘텐츠(뉴스, 라이브 스코어, 대회 일정, 세계 랭킹)는 **로그인 없이** 이용 가능합니다.
로그인은 '관심 선수 알림', '알림 설정', 그리고 **커뮤니티 · 라이브 채팅 참여**에 사용됩니다.
사용자 생성 콘텐츠(글·댓글·채팅)는 **로그인한 사용자만 작성**할 수 있습니다.

```
이 앱은 배드민턴 뉴스, 실시간 경기 스코어, 대회 일정, 세계 랭킹 정보를 제공합니다.

[사용자 생성 콘텐츠 (Guideline 1.2)]
이 앱은 사용자 생성 콘텐츠를 포함합니다.
 (1) 커뮤니티 탭 — 게시글, 사진, 댓글, 대댓글
 (2) 라이브 매치 채팅 — 경기별 실시간 텍스트 채팅
작성은 로그인한 사용자만 가능합니다.

모더레이션 체계:
· 이용규칙 동의 — 커뮤니티 첫 글 작성 전에 "불쾌한 콘텐츠 무관용" 이용규칙 동의를
  받으며, 동의 여부는 서버(데이터베이스 함수)에서 강제해 미동의 상태로는 작성이
  거부됩니다. 이용규칙은 내정보 > 커뮤니티 이용규칙에서 언제든 다시 볼 수 있습니다.
· 콘텐츠 필터 — 커뮤니티 게시글·댓글은 서버의 금칙어 사전을 참조하는 트리거가
  검사하며, 걸리면 저장 자체가 거부됩니다.
· 신고 — 게시글, 댓글, 사용자를 신고할 수 있습니다. 라이브 채팅은 메시지를 길게
  눌러 작성자를 신고하며, 문제가 된 메시지 본문이 신고 내용에 함께 접수됩니다.
  사유는 스팸/광고, 욕설/비방, 음란물, 불법 정보, 개인정보 노출, 기타 6종입니다.
· 자동 숨김 — 신고가 임계값에 도달한 게시글·댓글은 운영자 확인 전에 서버가 즉시
  숨깁니다. 음란물·불법 정보는 1건, 그 외 사유는 3건이 임계값입니다.
· 24시간 이내 조치 — 신고가 접수되면 서버가 운영자 전원에게 즉시 푸시 알림을
  보내며, 운영자는 앱 안에서 해당 게시글·댓글을 숨김/삭제하거나 작성자의 커뮤니티
  이용을 정지시킬 수 있습니다.
· 차단 — 어떤 사용자든 차단할 수 있습니다. 차단하면 그 사용자의 글·댓글은 서버에서
  걸러져 보이지 않고, 상대에게도 내 글·댓글이 보이지 않습니다(양방향). 라이브 채팅
  메시지도 즉시 사라지며 이후 메시지도 표시되지 않습니다. 커뮤니티와 라이브 채팅이
  같은 차단 목록을 공유하므로 한 번 차단하면 두 곳 모두에 적용됩니다.
  차단 해제는 내정보 > 차단한 사용자에서 할 수 있습니다.
· 개발자 연락 — 내정보 > 도움말 / 피드백 보내기에서 개발자(cuunit.store@gmail.com)
```

## 제출 전 사람이 해야 할 일 (App Store Connect — 코드로 처리 불가)

이번 버전부터 앱에 **사용자 생성 콘텐츠가 포함**됩니다. 아래는 App Store Connect
웹에서 직접 해야 하는 작업이라 코드 변경으로 끝나지 않습니다.

- [ ] **연령 등급 재설문** — 등급 설문의 *사용자 생성 콘텐츠 / 무제한 웹 접근* 항목에서
      "사용자 생성 콘텐츠"를 **있음(예)** 으로 바꿉니다. 커뮤니티 글·댓글·사진과
      라이브 채팅이 모두 여기에 해당합니다. 이 설문을 고치지 않으면
      "메타데이터가 앱과 다르다"로 리젝됩니다.
- [ ] **App Privacy 재신고** — 수집 항목에 **사용자 콘텐츠(User Content)** 를 추가합니다.
      · 게시글·댓글·채팅 메시지 본문 (기타 사용자 콘텐츠)
      · 커뮤니티 프로필 사진 및 첨부 사진 (사진)
      · 닉네임 (사용자 ID / 이름)
      용도는 '앱 기능', 사용자 신원과 **연결됨**, 추적에는 사용하지 않음으로 신고합니다.
      기존 항목(이메일, 기기 식별자, 사용 데이터)은 그대로 둡니다.
- [ ] **데모 계정 준비 및 입력** — 위 '데모 계정' 항목의 조건(타인 글·댓글·채팅 메시지가
      보이는 상태)을 갖춘 계정을 만들고 App Store Connect 에 입력합니다.
      제출 직전에 실제로 로그인해 **신고 → 차단 → 차단 해제**까지 한 번 돌려보세요.
- [ ] **지원 URL / 개인정보 처리방침 URL** 실제 주소로 교체.
- [ ] **App Review Notes 붙여넣기** — 위 '비고' 블록을 그대로 복사해 넣습니다.
